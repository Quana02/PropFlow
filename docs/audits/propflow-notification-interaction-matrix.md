`FinanceNotificationCreated` là một envelope SignalR dùng chung cho notice in-app, theo user. Event mang notification ID, title/message, action path, read flag, timestamp và loại nguồn. `sourceId` thuộc kết quả HTTP. Ánh xạ frame với record theo notification ID. Dùng route HTTP kiểm quyền lại sau khi mở link. [Publisher](../../src/Modules/Communication/Infrastructure/FinanceNoticePublisher.cs) · [Hub](../../src/Modules/Communication/Presentation/ResidentNotificationHub.cs) · [API](../../src/Modules/Communication/Presentation/ResidentNotificationsController.cs)

`NotificationReadStateChanged` cập nhật trạng thái dùng chung sau khi thao tác đánh dấu đã đọc thay đổi ít nhất một hàng của người gọi. Frame rỗng gửi qua user SignalR. Chrome kiểm hai tab, phiên độc lập, thu hồi phiên, đối chiếu badge với API khi đọc tất cả đồng thời có giao việc mới và lấy lại trạng thái bị lỡ sau reconnect. PostgreSQL kiểm hai alias, cập nhật đồng thời, no-op và tài khoản ngoài phạm vi.
